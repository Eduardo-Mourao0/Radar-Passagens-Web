# RadarPassagens Web

Dashboard para cadastrar e monitorar rotas aéreas usando a API do repositório `Radar-Passagens`.

## Como executar

1. No backend, execute `npm run start:dev`.
2. Neste repositório, execute `npm start`.
3. Abra `http://localhost:5173`.

O servidor local encaminha as chamadas do dashboard para `http://localhost:3000`, portanto não é necessário configurar CORS na API.
